# 详情字段覆盖与按需读取边界

本表先于第 5 项优化编写（2026-11-15）。覆盖依据是当前采集路径，不能把合成样本当作官网实测。每次采集必须同时保存商品 serverId/eid、采集版本和本次源版本；采集中源版本变化应保留 partial。已有数据只有与同一商品、同一源版本的实际页面采集逐项相等，才可省略对应动作。

| 字段组                           | 已有数据与读取入口                                                                                                              | 身份和版本证据                                           | 缺失含义与回退                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------- |
| 人物基本属性、修炼、输出/抗性    | 当前人物标签可见 fields/tables/text；原始角色数据仅归档，不猜字段映射                                                           | 绑定详情根、serverId/eid、sourceRevision、captureVersion | 缺标签或未加载为 partial；仍点击标签及实际子标签                           |
| 七个师门、辅助、生活技能         | 当前技能图标 data_skill_type/name/level 与可见文本；解析器 all_skills + school_skill 的 id/name/slot 只作独立交叉证明           | 同次角色原文与解析器/配置版本                            | 不以“主技能”一项代替七槽；缺槽、无名称/等级时 partial；按需切换技能页      |
| 身上装备、仓库、拆卸、御魂、法宝 | 官方容器 RoleUsingEquips/RoleStoreEquips/RoleSplitEquips/RoleYuHun 的逐图标 attrs，描述和必要提示框；原始 worn 数据补充同件等级 | 同商品、容器位置、名称/模型、原始属性与 tooltip 来源     | 缺描述按需悬停；缺容器或未读图标不能当空；仅官方空容器证据可证明零         |
| 宝宝基本属性、资质、成长         | 每只已选宝宝的可见详细信息与入口数量                                                                                            | 商品、宝宝索引/选中状态、同次源版本                      | 未选、加载中、入口/总数不等为 partial；仍逐只点击                          |
| 宝宝技能、装备、内丹             | 各独立分区的图标 attrs、可见声明数量和必要提示框                                                                                | 当前宝宝、分区、名称/模型/等级、skillObservation         | 缺分区不等于空；数量和声明必须相等；装备缺描述悬停；条件技能不冒充当前技能 |
| 普通/进阶坐骑、属性方案          | 解析器明确存在的 AllRider / jinjie_rider_info + 实际坐骑标签/条目                                                               | 同角色原文、解析器版本、条目索引                         | 未提供 AllRider 不得默认为零；已有成长不代表条目全部字段，仍点击实际条目   |
| 神器、货币、靓号、化圣           | 解析器 shenqi/result、iCash/iSaving/iLearnCash/xianyu、idbid_desc、i3FlyLv                                                      | 商品、源版本与独立身份观察                               | 明确 false/零与未提供分开；缺数据仍记录 issues，不凭默认值宣称完整         |
| 锦衣/外观                        | 实际标签可见 text/fields/tables 和图标                                                                                          | 商品、详情根、源版本                                     | 无标签/未读为 partial；未证明 raw 映射完整，保留点击                       |
| 玩家之家                         | 实际标签可见 text/fields/tables 和图标                                                                                          | 商品、详情根、源版本                                     | 未证明 raw 映射完整，保留点击；无标签/未读为 partial                       |

验证方法：使用一份含所有上述非空资产的离线页面，独立登记页面原始数据与期望数量，再运行真实 Playwright 采集和扩展观察/原生语义采集。比较字段、数量、位置和来源，不能仅以 captureIssues 为空判定等价。缺失样本和源变化必须单独覆盖。

本轮优化范围仅为已有属性可完整表达的技能名称、类别、等级与分区。装备出现“等级和一个属性”不能证明提示框字段齐全，人物和宝宝装备仍悬停；御魂 JSON、未解析名称和未完整说明继续按需读取。所有主标签、子标签、宝宝、坐骑和孩子条目继续访问。网页 raw 尚未证明覆盖完整资产，不允许整页或整组跳读。

## 逐字段记录契约

采集版本升级至 10；既有 9 版不具有本轮来源证明，须重新核验。`sourceEvidence` 的 serverId/eid 和 initialRevision/finalRevision 约束整份字段表，缺失或源版本不一致不能进入完整分析。压缩后仍保留此表。

| 归档字段路径                                                             | 来源与含义                                                                                                                                | 缺失处理                                                              |
| ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `tabs.<标签>.fields[i].<名称>`                                           | 可见字段原值；人物/修炼的名称、等级、修炼和属性逐项保留                                                                                   | 未加载不补默认值，保留 partial                                        |
| `tabs.<标签>.tables[t][r][c]` / `.text`                                  | 实际可见表格每格及原文，保留未映射的新字段                                                                                                | 不以导航原文代替资产正文                                              |
| `tabs.技能.items[i].name/category/level`                                 | 元素、官网模型或当前技能分区，名称/类别保留实际 source；师门七槽与解析器交叉校验                                                          | 辅助、生活和师门仍访问实际分区；未知不推断等级                        |
| `tabs.<标签>.items[i].description`                                       | 本轮实际提示框标 `tooltip`，已有描述标 `element-attributes`；官网模型名称/分类分别保留 `official-model` / `official-slot` / `description` | 提示框不完整、失去条目身份或来源冲突为 partial                        |
| `.items[i].attributes.<属性>` / `.level` / `.location`                   | 元素属性与官方容器位置；同商品穿戴原文补等级标 `official-role-parser`                                                                     | 原文不匹配不补等级，零级与未知分开                                    |
| `.containers.<容器>`                                                     | 官方容器可见且逐图标数已记录；零图标仅此时为 explicit-empty                                                                               | 缺容器、遮挡、未读图标不当零                                          |
| `tabs.召唤兽/孩子.pets[p].fields[i].<名称>`                              | 每只宝宝独立的名称、类型、等级、成长与六资质                                                                                              | 入口真实节点身份、所选宝宝和总数均须一致，重排/替换停止并保存 partial |
| `.pets[p].skills/equipment/innerSkills[i]`                               | 每项名称、等级、类别、说明和当前/条件技能证据；宝宝装备继续提示框读取                                                                     | 分区缺失不当零，实际数与声明数分别核验                                |
| `tabs.坐骑.content` / `tabs.锦衣/外观.content` / `tabs.玩家之家.content` | 从详情正文读取，排除主导航、header和临时提示框；明确无资产为 explicit-empty                                                               | 缺失、空白、加载中或“暂无信息，请稍后”均 unknown 并阻止完整保存       |
| `tabs.坐骑 / 第n只.fields[...]`                                          | 每个入口的全部实际字段，成长以解析器 AllRider 独立核验                                                                                    | 原始 riders 未提供不默认为空；仍逐条访问                              |
| `valuation.fields[i].<名称>` / `valuation.source.<来源组>`               | 官方角色解析器、模型和配置关联的同商品证据；资产、技能、普通/进阶坐骑分别记录                                                             | 未提供是 unknown；显式零和 false 保持原义                             |

每条记录的 state 为 observed、explicit-empty 或 unknown。动态字段表用于保留实际读取的全部字段，另由师门、装备、宝宝完整性契约及三个正文必需项判断完整性，不把“列出了已有字段”当作“缺失字段不存在”。原文 getter 或序列化失败也保留此前已读标签和失败原因。

## 完整离线样本与证据边界

`tests/fixtures/complete-role.mjs` 在页面渲染和采集前登记同一份独立期望账本：人物名称/175级/修炼25/25/气血5000、七师门及辅助/生活技能、身上武器与仓库头盔各一件（含提示框额外命中/魔法字段）、两只宝宝（每只六资质、成长、两个技能、一个装备、一个五层内丹）、两只普通坐骑、孩子、锦衣/祥瑞、房屋/庭院及四项货币。页面原始解析数据与期望账本独立传入真实采集器。

`detail-field-coverage.browser.test.ts` 对比已有属性与缺失描述两种页面的完整字段/数量/位置，分别通过实际 Playwright 采集器和真实 MAIN/ISOLATED + 原生语义采集器验证同一账本；另核对 tooltip 来源、无无效技能悬停、必需页面访问，以及缺 raw/缺宝宝分区/原文异常保留 partial。`field-evidence-review.test.ts` 独立覆盖来源、导航诱饵、空白、加载提示和明确无资产。

该样本是合成离线数据，尚不能证明官网所有可能字段的完整映射。未被此账本独立证明的字段组继续实际点击/悬停，实际官网观察与原生桌面输入验收单独记录。
