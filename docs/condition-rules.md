# 自由文字入榜条件

在“分析设置 → 入榜条件”输入文字，点击“解析文字条件”，核对每条执行口径后保存。条件列表仍为单层，且／或从上到下依次合并；例如 `A 或 B 且 C` 按 `(A 或 B) 且 C` 计算。

解析只将文字转换为可执行规则，不分析商品、不保存设置、不启动采集。编辑文字会立即清除其旧规则；取消、关闭设置或继续编辑时，旧解析响应不会覆盖新输入。已有价格控件可直接使用，不需模型解析。

## 判断方式

AI 只解释规则，不给商品返回“满足／不满足”。程序根据采集资料执行字段读取、集合筛选、去重计数、求和、最小／最大值、算术、比较和逻辑操作。每项结果包含计算说明和采集依据。

当前字段目录覆盖挂牌价、裸号估值、区服、人物等级／门派／速度／气血／伤害／防御／法伤，以及装备和召唤兽的等级、名称、类别、当前技能、技能数、成长、宝石／精炼等级及部分装备属性。目录可扩展；用户输入的阈值、统计对象、筛选和组合均为规则数据，不按固定句子执行专门分支。

示例：

- 人物装备、灵饰、宝宝装备和召唤兽的合计数量大于8。
- 至少3件等级不低于100级的人物装备。
- 至少一只召唤兽当前技能包含须弥真言。
- 人物等级不低于175级，且门派为化生寺。
- 挂牌价不超过裸号估值的90%。
- 灵饰的最低等级不低于100级。

“装备和宝宝合计”沿用本项目已确认的四项口径：人物装备＋灵饰＋宝宝装备＋召唤兽。法宝、灵宝、神器、上古玉魄、元身和普通道具不作为人物装备；宝宝饰品不作为宝宝装备。计数包含0级和野生召唤兽，明确排除时才筛掉；交易查价排除项不等于库存不存在。其他用户或产品采用不同口径时，应修改编译器提供的口径说明并重新解析，不能默默替换。

只估算裸号价格时，条件仍可读取已完整采集的装备、灵饰、宝宝装备和召唤兽资料，不会为判断条件自动补采或查价。实例标识重复时去重；相同名称／描述但标识不同的物品分别计数。

## 无法判断

缺少资料、数量完整性未核验、字段冲突、类型不明、除零及空集合的最值不会按0处理。人物装备与灵饰的类别不明时，单类计数不可确定；两类合并总数可在库存整体完整时计算。

“配置很好”“值得买”等主观标准、外部成交价、收益预测和目录之外字段不会被编成常量满足。解析结果显示“需明确口径”或“暂无法自动判断”，并给出原因。保存这些规则后结果为无法判断。不能支持的子句不会被删掉后假装解析成功。

单条未知不等于满足；最终按三态逻辑合并。例如“不满足 且 无法判断”为不满足，“满足 或 无法判断”为满足；最终无法判断的商品不自动入榜。价格仍按分比较。

## 现有结果与历史

保存条件后，当前榜单和详情根据当前规则及与原分析匹配的资料即时重算，不必为了修改数量或筛选条件逐商品调用AI。裸号公式、估值参数、行情和采集来源的有效性检查保持独立；实际价格资料或估值规则变化仍需重新分析。

旧AI的条件状态不会参与当前入榜计算。未解析的旧文字条件需重新解析。历史分析JSON与原始AI返回保留，历史条件记录带有提示，不能当作当前规则结果。缓存同时区分当前配置、引擎版本和资料版本。

## 运行边界

编译器使用有字段白名单和类型检查的规则数据；不会执行模型代码、任意对象路径、网页指令或网络请求。每条规则最多120节点、12层，一次最多59条文字条件，每条最多1000字。解析口径仍需用户核对；类型正确不能证明模型对自然语言的理解一定正确。

`POST /api/analysis/conditions/compile` 只返回解析后的条件树。保存仍走原有配置冲突检查。接口支持取消及超时，未解析的文字条件不能直接保存为自动入榜条件。

## 只读实库审计

使用现有受管本地服务解析，或重放已有编译缓存，再读取归档的采集快照与对应估值进行计算。不要在源代码仓库中保存私有商品原文或完整报告。运行命令及独占运行方式见 `node scripts/condition-rules-audit.mjs` 的参数提示。

服务已部署本功能时，可让受管服务完成一次解析及其运行文件清理：

```sh
vp exec node scripts/condition-rules-audit.mjs \
  --database /absolute/path/to/data/cbg.sqlite \
  --compile-url http://127.0.0.1:5173/api/analysis/conditions/compile \
  --output /private/tmp/rules-audit.json
```

独立进程直接解析时必须取得项目的独占Codex服务租约；已有服务持锁时会在AI调用前拒绝，不会抢占、借用或绕过清理保护。DeepSeek或编译缓存重放不需要Codex租约。

已编译规则可重复重放，不再次调用AI：

```sh
vp exec node scripts/condition-rules-audit.mjs \
  --database /absolute/path/to/data/cbg.sqlite \
  --compiled-json /private/tmp/rules-audit.json.compiled.json \
  --output /private/tmp/rules-audit-replay.json
```

审计只读数据库，不使用真实采集浏览器。价格和官方召唤兽数量有独立计算对照，另验证同义规则、阈值单调性及已知误入榜案例；不将同一实现的重复计算当作全部正确性的证明。
