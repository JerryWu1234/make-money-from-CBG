# 扩展观察生命周期与回调边界

MAIN 和 ISOLATED 初始不安装业务观察。扩展绑定后启用一套观察；`stop`、`unbind`、`pagehide` 清除业务事件监听、定时任务、MutationObserver、网络钩子和未完成读取。控制入口保留，供同一文档重新绑定。重绑先清理旧代次，再分配新 token，不叠加包装。

MAIN 每秒读取公开状态，及时发现登录变化。公开目录读取集中经过缓存入口：入口函数或地址变化时目录缓存失效，目录缓存最长 5 秒；角色解析按原文、解析器与身份区分，缓存最长 1 秒；显式刷新跳过缓存。相同 render 合并，ISOLATED 的连续事件在 100 毫秒内合并为一次捕获。两个世界都校验绑定 token；MAIN 还校验读取序号和文档地址，digest、fetch、XHR 和回调晚到不能覆盖新代次。ISOLATED 清理并隔离已排队的延迟任务。

正常绑定时，快照发生实质变化、显式捕获或距上次发送约 4 秒时发送。4 秒任务执行新的 DOM 读取。心跳保留语义 revision、业务回调的 eventId/requestId/observedAt 和提交归属，不把旧回调改为新提交。当前桥协议和 Node 新鲜度校验使用完整快照，所以心跳仍发送有大小上限的完整快照；没有引入缺少字段的增量协议。

停止后没有周期观察。下一轮若发现快照超过 10 秒，Node 先发送只读 `observe`，等待请求起点之后的新观察，再执行原有权限和恢复核验。宿主对此命令只转发给扩展，不调用输入 helper、不授予活动租约，也不改变停止状态；伪造的 observe proof 不能进入输入分支。观察本身不持有防休眠断言。

worker 在每个异步绑定、解绑和保存边界重新核对控制代次。旧操作的晚到 ACK 只可按返回的 observer token 清理自己的观察，不能停止新绑定、覆盖用户的新绑定或删除新的导航。按钮停止、绑定标签关闭和意外导航的状态消息包含被停止的文档和绑定身份。Node 只对当前连接与当前绑定首次收到的匹配状态执行完整停止：撤销活动、取消等待、停止宿主输入，并清除续期任务；重复消息和旧绑定状态不会再次撤销新活动。宿主的停止确认不再向宿主发送停止命令。

`ajax_with_recommend` 收到调用方的原 options 对象和原 data 对象，额外参数、调用 receiver、返回值和抛出的异常保持原样。支持的 options 必须以自有数据属性保存 data，并以可写、可配置的自有函数属性保存回调。钩子保留属性的 enumerable/writable/configurable 标志；回调通过 `Reflect.apply` 保留 receiver、参数、返回或异常及调用次数。网站保存 options、稍后读取回调的路径仍可观察。首次 terminal callback 或解绑后恢复原回调描述符；网站自行替换的属性不被覆盖。

这是有限的回调观察能力。等待回调期间，回调属性的函数引用会改变，不能声称函数引用、name、length 等完全透明。冻结对象、accessor 或无法安全安装的描述符原样透传，不生成可接受的请求归属。某个 options 对象在同一文档再次使用时，旧请求立即失去归属，旧钩子恢复；第二次调用不复用旧 requestId。即使网站保存旧 wrapper，晚到调用也不能归给后来的请求。不同 options 对象使用相同条件并发、乱序完成，仍分别记录请求与回调。fetch/XHR 的原调用保持返回及异常；URL 对象等需要额外用户代码求值的参数不作字符串强制转换。

固定回归仍要求请求、成功回调和对应商品 DOM 三者一致。无归属、旧回调、缺失或错误服务器、错误商品身份，以及仅滚动或无关 DOM 变化，都不能形成新的提交证明。
