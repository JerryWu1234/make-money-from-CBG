# 真实工作页截图证据

实现前列出的失败方式：

- 生产 Chrome 尚未连接、断开，或工作页在读取时关闭。
- 页面仍在导航、控件尚未提交，或截图前后 URL、控件、商品和可见内容变化。
- 登录、二维码、安全验证或账号信息进入画面。
- 页面跳到非藏宝阁网站，不能继续读取或截图。
- 截图超时、DOM 读取超时，或证据目录写入失败。
- 同一稳定状态被反复保存，或页面停留时间短于轮询间隔而漏取。
- 将截图哈希、原始描述哈希误当成生产报价的来源文本哈希。

采集器只使用本次生产连接已经附加的官网工作页，不另建 Chrome 连接，不导航、点击、悬停或滚动。每轮结束后至少等待750毫秒，多页串行读取会延长实际间隔；读取和截图均有等待上限，失败记入清单，不控制业务队列。

每份稳定证据包含截图（搜索表单整页、详情页当前视口）、截图前后原始控件值、公开查询参数、主商品身份、可见文本、时间和独立 SHA-256。截图前后状态不一致时丢弃图像，记为缺失。相同页面与查询状态去重；短暂页面可能漏取，详情页视口以外内容未被截图，不能声称覆盖了每次网站请求。

本轮没有HTTP请求监听器，`submittedArgs`只代表页面公开状态，不代表独立记录的实际HTTP参数。最终索引状态为`indexed_review_required`，仍须逐角色审核关键证据覆盖；缺失时必须报告，不能用最终报价截图补充证明整个操作过程。

登录、二维码和安全验证页不截图；账号区域遮盖，密码、令牌及认证字段不写入证据。每次测试执行使用独立证据子目录，`index.json` 索引图像和JSON的哈希。最终运行manifest索引该清单。原始截图与侧写只能证明观察到的页面状态；审查时仍需按商品身份、实际参数和时间关联原始采集及报价记录。
